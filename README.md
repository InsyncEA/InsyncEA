# InSyncEA Website

The official website for **InSyncEA**, providing Executive Assistant and Business Operations Support for founders, startups, and growing businesses.

**Website:** https://insyncea.com

---

## About

This repository contains the source code for the InSyncEA website.

The site is built as a lightweight static website focused on:

- Executive Assistant services
- Business Operations Support
- Customer & Partnership Operations
- Administrative Support
- SEO-focused educational content
- Case studies
- Business resources

The website emphasizes performance, accessibility, semantic HTML, and technical SEO.

---

## Features

- Responsive design
- Semantic HTML5
- SEO-optimized pages
- Structured data (Schema.org)
- Open Graph support
- JSON-LD
- Internal linking strategy
- Blog with related articles
- FAQ schema
- Fast-loading static pages

## SEO

The website follows SEO best practices, including:

- Semantic HTML
- Clean URL structure
- Canonical URLs
- Meta descriptions
- Open Graph tags
- Twitter Cards
- Breadcrumb Schema
- BlogPosting Schema
- FAQ Schema
- Internal linking
- Optimized images
- Mobile-first responsive design

## Performance

The website is designed to be lightweight and fast:

- Minimal JavaScript
- Optimized images
- Deferred scripts
- Responsive layouts
- Accessible navigation
